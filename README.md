# Kids Health Academy — Frontend MVP

Kazakh-language pediatric health education portal built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## What's included

- Responsive landing page and navigation
- Category browsing and article filtering
- Live article search
- Article preview modal
- Newsletter form interaction (frontend demo only)
- About section and medical disclaimer

## Notes

Article text and newsletter submission are demo content. No backend, user accounts, persistence, or real email subscription is connected yet. Medical content must be reviewed by qualified pediatric professionals before publication. Images are loaded from Unsplash and require an internet connection.
